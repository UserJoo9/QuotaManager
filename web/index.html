Users & devices

Unmanaged / rogue devices

Active on your network but not leased by the quota DHCP — a static-IP device bypasses the box (its traffic is never counted or blocked). The ARP gateway-lock cuts its internet when enabled.

Bundle configuration

Your monthly internet allowance and when the quota period rolls over. Edit anytime — the dashboard takes ownership of the bundle after your first save.

Bundle recharged

Bought more data mid-month? Add it here — every auto user's share is recalculated without resetting the period.

Guest mode

Every new device that joins the network becomes a guest with its own small allowance. Guests survive disconnects and are deleted when the month resets.

Connection & security

Stop new connections

While on, a brand-new device is blocked on first sight. Already-registered devices join normally.

Decline random MACs

Block new devices using randomized/privacy MAC addresses from joining the network.

MAC whitelist / blacklist

Allow-list MACs are never quota-blocked, whatever their usage. Deny-list MACs are always cut, even when their user is fine. Both apply to existing devices on the next tick — one MAC per line (or comma-separated).

Speed limits & latency (bufferbloat control)

WAN — internet

LAN — internal transfers

Maximum allowed speed for internal local network transfers (0 = 1000 Mbps default).

VPN share (TUN mode)

Route all network traffic through the gateway\'s active VPN tunnel (TUN mode).

    WAN mode

    Protect internal network from upstream.

    Gateway dials PPPoE directly for maximum security. Router admin page remains accessible.

    Select mode and press Apply to automatically restart the gateway.

    PPPoE credentials for WAN mode — from your ISP card or the router's WAN status page. Leave WAN interface empty unless you use the two-NIC layout.

    Not sure the credentials work? Test them first — a throwaway dial that reports whether the ISP accepts them, without changing anything.

    Guide — how to switch your router

    How to switch:

    1. Put the router in BRIDGE / MODEM mode.
    2. Enter PPPoE credentials above and click Apply now.
    3. Two-NIC fallback: Set AP mode, connect ONT to NIC1, AP to NIC2. Enter NIC2 name in WAN interface.

    Reverting: Press Revert to LAN and undo router bridge mode.

    Firewall

    LAN mode

    A separate nftables table (inet quota_firewall) layered before the quota engine — denied traffic never consumes the bundle, and quota cuts still apply. Posture is derived from the topology: LAN is permissive-out with explicit denies; WAN (Strong mode) adds a default-deny for NEW inbound on ppp0.

    Custom rules

    Ordered allow/deny rules on input (the box) or forward (the network). A deny with no port/dst scope that covers the client subnet is refused automatically — you can never lock the dashboard out.

    Protection

    Enforce HTTPS

    Generate a self-signed TLS certificate and enable encrypted dashboard access in one click. The browser will show a one-time warning you accept — after that the connection is encrypted and the WAN-over-HTTP warning disappears.

    Remove HTTPS?

    This will delete the TLS certificate and switch the dashboard back to plain HTTP. Your admin session will be preserved but credentials will travel unencrypted.
