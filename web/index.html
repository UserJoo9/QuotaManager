    WAN mode (strong security)

    By default the box sits behind the router: clients get their own subnet from the quota DHCP and the router keeps WiFi + NAT. A determined user can still bypass the quota by setting a static IP + the router as its gateway.

    WAN mode closes that hole at the topology level: the box itself dials the PPPoE line (public IP on ppp0) and the router becomes a pure bridge/AP — a static-IP device then has no second router to bypass to, so every byte crosses the box.

    Router admin stays reachable: the box keeps the router's LAN address as a secondary alias, so you (and every device) can still open the router admin page — no extra commands on any device.

    Select the mode and press Apply — the gateway rewires itself (NIC, DHCP/DNS, the PPPoE dial) and restarts automatically. No setup script, no terminal. The saved preference also applies on the next restart.

    PPPoE credentials for WAN mode — from your ISP card or the router's WAN status page. Leave WAN interface empty unless you use the two-NIC layout.

    Not sure the credentials work? Test them first — a throwaway dial that reports whether the ISP accepts them, without changing anything.

    Guide — how to switch your router

    Two physical layouts. Both work with the routers most Egyptian homes have (WE ZTE/Huawei, Orange Livebox, Vodafone, e&).

    1. Put the router in BRIDGE / MODEM mode (WAN↔LAN bridged, NAT + DHCP off, WiFi on). Look for Bridge, Modem or WAN mode in the router's WAN settings. ISP-locked combos may need a bridge-unlock code or an ISP call.
    2. Enter your PPPoE credentials in the fields above (username + password, from your ISP card or the router's WAN status page). Press Test PPPoE connection first — it dials a throwaway link and tells you if the ISP accepts them — then Apply now. The gateway dials the line itself and restarts.
    3. Two-NIC fallback (universal): if your router can't bridge, set it to AP mode (WiFi only, DHCP off — supported by every router), connect NIC1 of the box straight to the ONT/modem to dial PPPoE, and NIC2 to the AP. Put the second NIC's name (e.g. eth1) in the WAN interface field. Needs a cheap USB Ethernet dongle.

    Reverting: press Revert to LAN above — the gateway restores the router uplink and restarts. The router itself must be back in routed mode first (undo the bridge).
